What changed this round

If you extracted under the previous template, these are the differences. Every changed field is also flagged inline below.

New section

A conditional block gated on “no NCT”. Country, Trial Phase, Design and Blinding are now filled only when the study has no ClinicalTrials.gov (NCT) number — for NCT studies these come from the registry automatically. The gate is NCT specifically, not “registered”: an ANZCTR / ISRCTN / EudraCT / Dutch study still needs them by hand.

Reworked

Blinding records who was masked, not a level. Tick the parties (participant, care provider, investigator, outcomes assessor) — never “single / double / triple”. The level is worked out later by counting.

New field

Pooled study? A checkbox, ticked only when a paper pools several trials. It replaces “Pooled” as a phase value and drives how the paper links to its trials.

New field

Country / countries where the trial was conducted — study sites, not author affiliations. In the no-NCT block.

New field

Design — parallel / crossover / factorial. (No “single-group”: in a database of randomised trials it shouldn’t occur. No “quasi-randomised”: that’s a screening question.)

Changed

Trial Phase dropped its “Unregistered” and “Pooled” values — those are now derived from the registry cell and the Pooled checkbox — and gained Not Reported.

Changed

N randomized / N analyzed now use an explicit NR. A blank means “not extracted yet”; NR means “the paper doesn’t report it”. N analyzed is the field you can almost always fill.

Split in two

Age is now Age metric + Age value, so a median or a range is captured honestly instead of forced into a mean-or-nothing box.

New field

%Female — a single number (0 = all male, 100 = all female).

Removed

Sex-specific population? is gone — %Female subsumes it (0 or 100 = single-sex).

Restored

Microdosing study? — the flag the prior revision dropped is back.

Expanded

Comparator gained three options for dose-ranging and co-administration designs, and low-dose active was renamed low-dose intervention drug (a low dose isn’t “active”). See the dedicated comparator guide for worked examples.

New fields

Registration / parent not reported (found by search). Two checkboxes that flag when a study’s registration or parent trial exists but the paper doesn’t disclose it — found only by independent search. A CONSORT item 23 / ICMJE reporting failure, and one most reviews can’t measure because they trust the paper. See the tool in Identification below.

Read once

Conventions that apply everywhere

Four rules that recur across the template. Getting these right is most of what keeps the data clean.

Two separators

In free-response fields, use ;. Inside a single Other box, separate several free-text values with + — the Covidence other-box rejects semicolons. So Other: harmine + banisteriopsis is two values.

NR vs blank

On a numeric field, type NR when the paper doesn’t report the value. Leave it blank only when you haven’t extracted it yet. A blank never means “not reported” — that’s always an explicit NR.

Multi-select means all that apply

Most fields take several ticks. Options answer different questions and aren’t alternatives — a factorial dose study is often placebo and dose-ranging and component-alone. Don’t stop at one.

Don’t infer, don’t escape

Record only what the paper states; where it’s silent, use the field’s “not reported” path rather than guessing. Reach for a controlled option before Other — the vocabulary is there so the same thing is coded the same way every time.

Trial Registry Number

text

The NCT or other registry id for this report. If a pooled study lists several, separate them with ;. List the NCT first if there is one — it’s the id the enrichment uses.

One trial, two registries ≠ pooled. A study carrying both a Dutch ABR and OMON number, or an NCT and a EudraCT, is one trial cross-registered — leave Pooled unticked. Only tick Pooled for a genuine multi-trial analysis.

Registration not reported in the paper (found by search)

checkbox · default offNew

Tick yes only when you had to find the registration yourself because the paper doesn’t report it — you still enter the id above, but the paper failed to disclose it. Leave blank when the paper reports its own registration (the normal case) or when no registration exists at all.

yes

Finding registrations the paper hides — Trial Registration Tracer

When a paper reports no registration, use the custom GPT Trial Registration Tracer before recording the study as unregistered. It works best when you upload the paper’s PDF and run its default prompt: “I uploaded a PDF. Trace the trial registration or parent study DOI.” It searches the paper first, then registries and related publications, and returns a verdict plus an evidence table with an explicit provenance line for the registration and any parent.

Base your ticks on the provenance line, not just the id:

  • reported “directly stated / cited in target paper” → enter the id, leave the box unticked.
  • not reported “manually retrieved / not in target paper”, or only partially signposted (a trial acronym but no id a reader could follow) → enter the id and tick the box.
  • don’t record “uncertain”, or a match below confirmed / strong candidate → don’t enter an id you can’t stand behind; note it in Notes instead.

Always confirm the match yourself — check the registry’s drug, N, population and dates against the paper before recording it. The GPT is a lead, not the final say.

Pooled study?

checkbox · default off New

Tick only if the paper pools data from several distinct trials. When ticked, skip Trial Phase, Design and Blinding unless every pooled cohort shares the same value. Country is still valid (record all cohorts’ countries). For pooled studies with NCT numbers the whole no-NCT block can be skipped.

yes

Section 2 · conditional

Fill only if there is no NCT number

Fill this block only if the study has no ClinicalTrials.gov (NCT) registry — even if it is registered elsewhere (ANZCTR, ISRCTN, EudraCT, Dutch). For NCT studies these fields come from ClinicalTrials.gov automatically, so leave them blank. A non-NCT registry is registered but is not auto-enriched, so it still needs this block by hand.

Parent study DOI

text

Only fill if this is a completely unregistered study that cites a parent/source trial. Exclude https://doi.org/. Pooled → separate with ;. This is what links multiple reports of one unregistered trial together.

checkbox · default offNew

(A softer norm than registration reporting, but still worth recording.)

Trial Phase

single-select Changed

Only record a phase if it’s explicitly written in the paper or registry. Not Applicable has real meaning — pick it only if the report/registry itself says the phase is Not Applicable (common for early pharmacology). Otherwise Not Reported.

Gone: “Unregistered” and “Pooled” are no longer phase values — registration is derived from the registry cell, and pooling from the checkbox.

Design

single-select + Other New

The trial’s design structure. Other takes free text for anything outside the list (put the description in its box).

parallelcrossover factorialnot reported Other

No single-group (a randomised trial has more than one group — if it looks single-group, question inclusion) and no quasi-randomised (alternation / day-of-week isn’t an RCT — a screening call).

Blinding

multi-select Reworked

Tick every party the paper explicitly says was masked. If it only states a level (e.g. “double-blind”) without naming who, tick participant + not-specified — do not infer the others. Tick open-label only if the study was explicitly unblinded across all parties.

participantcare provider investigatoroutcomes assessor not-specifiedopen-label not reported

Why roles, not a level: “double-blind” doesn’t say who — across registered trials it resolves to different pairs, and most trials mask three or more parties. Recording who preserves that; a level throws it away. care provider = the therapist / session monitor, relevant mainly in assisted-therapy protocols.

Section 3

Population

N randomized

number / NR Changed

Fill only if the paper gives a separate enrolled/randomized count, or explicitly says everyone completed with no dropouts (then enter that same N). Otherwise put NR — don’t infer it from the analyzed number.

N analyzed

number / NR Changed

The number the results are based on — the completer / final-analysis N. Usually stated plainly (“16 participants”, “16 completed”, “results in 16”). Multiple results/timepoints → the largest N the main outcome is based on (a judgement call). If the paper never states it, NR.

This is the anchor. You can nearly always fill it; N randomized is the “only if separately reported” field. Both integers → attrition is computable; an NR on either → attrition undeterminable, which is a real finding, not a gap.

Age metric

single-select + Other New

What the paper reports. Pick the metric, then put the number in Age value.

meanmedian rangenot reported Other

Age value

text / number

A range → enter as 18–27. If a trial reports means by arm, compute the N-weighted average (not valid for medians — put NR in the metric instead). If the metric is not reported, leave this blank.

%Female

number / NR New

The percentage female — 0 = all male, 100 = all female. From counts: F / (F + M) × 100. Reported by arm → N-weighted average. Not reported → NR.

This replaces the old “Sex-specific population?” question: a single-sex study is just 0 or 100 here, so tick it that way rather than leaving it NR.

placebo (niacin, mannitol, sugar pill, etc.) low-dose intervention drug other dose levels of the intervention (dose-ranging) intervention component alone (co-administration studies) co-administered component alone (co-administration studies) d-amphetaminedextromethorphan diphenhydraminemethylphenidate modafinilSSRI (escitalopram, etc.) waitlist/care as usualOther

Low-dose vs dose-ranging are independent. A designated near-inert control dose (e.g. 1 mg psilocybin) is low-dose intervention drug; three or more dose levels with dose as the variable is dose-ranging; a study can be both. A low dose of the study drug is never placebo. See the comparator guide for worked examples.

Outcomes — 15 domains

Each domain is its own multi-select. Tick every measure the study assessed within it; leave the domain blank if it assessed nothing there. Every domain has an Other box (use + for several).

A tick marked + opens guidance: which named instruments belong under it, and where the near-misses go instead. More will be added as reviewers ask — tell us which ticks are causing hesitation.

Drug experience questionnaires

Persisting (PEQ; not HPPD) Other

The field's standard measures of the acute drug experience all live under this one tick. Tick it once, however many of them a study ran — the specific instruments go in the measure text, not into separate ticks.

Ticks Acute
ASC (5D-ASC · 11D-ASC/OAV) MEQ (MEQ30 · MEQ43) CEQ intensity ratings VAS subjective-effect ratings EBI

Rule of thumb — ask what the instrument is about, not when it was filled in. If it asks about the drug effect (how strong, how strange, how mystical, how difficult), it is Acute. A questionnaire completed after the session asking what the session was like is still Acute; one asking how you are now is not. If a mood scale is administered during the session to capture the present state, it is still Acute.

Goes elsewhere
  • Persisting PEQ and other "what has changed since?" questionnaires — same domain, the other tick.
  • Safety & tolerability HPPD / persisting perceptual changes, and session adverse events.
  • Psychiatric mood and symptom scales (POMS, STAI, BDI), administered before/after the session.
  • Trial integrity blinding guesses and expectancy ratings.
  • Psychological process connectedness, insight, compassion and similar constructs measured as outcomes at follow-up.
  • Sensorimotor psychophysical and perceptual tasks — performance, not self-report.

Domains are independent: an ASC and a POMS in the same paper is two ticks, not a choice.
