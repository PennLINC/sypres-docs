Read once

Conventions that apply everywhere

Four rules that recur across the template. Getting these right is most of what keeps the data clean.

Two separators

In free-response fields, use ;. Inside a single Other box, separate several free-text values with + — the Covidence other-box rejects semicolons. So Other: harmine + banisteriopsis is two values.

NR vs blank

On a numeric field, type NR when the paper doesn’t report the value. Leave it blank only when you haven’t extracted it yet. A blank never means “not reported” — that’s always an explicit NR.

Multi-select means all that apply

Most fields take several ticks. Options answer different questions and aren’t alternatives — a factorial dose study is often placebo and dose-ranging and component-alone. Don’t stop at one.

Don’t infer, don’t escape

Record only what the paper states; where it’s silent, use the field’s “not reported” path rather than guessing. Reach for a controlled option before Other — the vocabulary is there so the same thing is coded the same way every time.

Trial Registry Number

text

The NCT or other registry id for this report. If a pooled study lists several, separate them with ;. List the NCT first if there is one — it’s the id the enrichment uses.

One trial, two registries ≠ pooled. A study carrying both a Dutch ABR and OMON number, or an NCT and a EudraCT, is one trial cross-registered — leave Pooled unticked. Only tick Pooled for a genuine multi-trial analysis.

Registration not reported in the paper (found by search)

checkbox · default offNew

Tick yes only when you had to find the registration yourself because the paper doesn’t report it — you still enter the id above, but the paper failed to disclose it. Leave blank when the paper reports its own registration (the normal case) or when no registration exists at all.

yes

Finding registrations the paper hides — Trial Registration Tracer

When a paper reports no registration, use the custom GPT Trial Registration Tracer before recording the study as unregistered. It works best when you upload the paper’s PDF and run its default prompt: “I uploaded a PDF. Trace the trial registration or parent study DOI.” It searches the paper first, then registries and related publications, and returns a verdict plus an evidence table with an explicit provenance line for the registration and any parent.

Base your ticks on the provenance line, not just the id:

  • reported “directly stated / cited in target paper” → enter the id, leave the box unticked.
  • not reported “manually retrieved / not in target paper”, or only partially signposted (a trial acronym but no id a reader could follow) → enter the id and tick the box.
  • don’t record “uncertain”, or a match below confirmed / strong candidate → don’t enter an id you can’t stand behind; note it in Notes instead.

Always confirm the match yourself — check the registry’s drug, N, population and dates against the paper before recording it. The GPT is a lead, not the final say.

Pooled study?

checkbox · default off New

Tick only if the paper pools data from several distinct trials. When ticked, skip Trial Phase, Design and Blinding unless every pooled cohort shares the same value. Country is still valid (record all cohorts’ countries). For pooled studies with NCT numbers the whole no-NCT block can be skipped.

yes

Section 2 · conditional

Fill only if there is no NCT number

Fill this block only if the study has no ClinicalTrials.gov (NCT) registry — even if it is registered elsewhere (ANZCTR, ISRCTN, EudraCT, Dutch). For NCT studies these fields come from ClinicalTrials.gov automatically, so leave them blank. A non-NCT registry is registered but is not auto-enriched, so it still needs this block by hand.

Parent study DOI

text

Only fill if this is a completely unregistered study that cites a parent/source trial. Exclude https://doi.org/. Pooled → separate with ;. This is what links multiple reports of one unregistered trial together.

Design

single-select + Other New

The trial’s design structure. Other takes free text for anything outside the list (put the description in its box).

parallelcrossover factorialnot reported Other

No single-group (a randomised trial has more than one group — if it looks single-group, question inclusion) and no quasi-randomised (alternation / day-of-week isn’t an RCT — a screening call).

Blinding

multi-select Reworked

Tick every party the paper explicitly says was masked. If it only states a level (e.g. “double-blind”) without naming who, tick participant + not-specified — do not infer the others. Tick open-label only if the study was explicitly unblinded across all parties.

participantcare provider investigatoroutcomes assessor not-specifiedopen-label not reported

Why roles, not a level: “double-blind” doesn’t say who — across registered trials it resolves to different pairs, and most trials mask three or more parties. Recording who preserves that; a level throws it away. care provider = the therapist / session monitor, relevant mainly in assisted-therapy protocols.

Section 3

Population

N randomized

number / NR Changed

Fill only if the paper gives a separate enrolled/randomized count, or explicitly says everyone completed with no dropouts (then enter that same N). Otherwise put NR — don’t infer it from the analyzed number.

N analyzed

number / NR Changed

The number the results are based on — the completer / final-analysis N. Usually stated plainly (“16 participants”, “16 completed”, “results in 16”). Multiple results/timepoints → the largest N the main outcome is based on (a judgement call). If the paper never states it, NR.

This is the anchor. You can nearly always fill it; N randomized is the “only if separately reported” field. Both integers → attrition is computable; an NR on either → attrition undeterminable, which is a real finding, not a gap.

Age metric

single-select + Other New

What the paper reports. Pick the metric, then put the number in Age value.

meanmedian rangenot reported Other

Age value

text / number

A range → enter as 18–27. If a trial reports means by arm, compute the N-weighted average (not valid for medians — put NR in the metric instead). If the metric is not reported, leave this blank.

%Female

number / NR New

The percentage female — 0 = all male, 100 = all female. From counts: F / (F + M) × 100. Reported by arm → N-weighted average. Not reported → NR.

This replaces the old “Sex-specific population?” question: a single-sex study is just 0 or 100 here, so tick it that way rather than leaving it NR.

Comparator Drug

multi-select + Other Expanded

Tick all that apply (this is where multi-select matters most). If the comparator is unclear, describe it in Notes.

placebo (niacin, mannitol, sugar pill, etc.) low-dose intervention drug other dose levels of the intervention (dose-ranging) intervention component alone (co-administration studies) co-administered component alone (co-administration studies) d-amphetaminedextromethorphan diphenhydraminemethylphenidate modafinilSSRI (escitalopram, etc.) waitlist/care as usualOther

Low-dose vs dose-ranging are independent. A designated near-inert control dose (e.g. 1 mg psilocybin) is low-dose intervention drug; three or more dose levels with dose as the variable is dose-ranging; a study can be both. A low dose of the study drug is never placebo. See the comparator guide for worked examples.

Section 5

Outcomes — 15 domains

Each domain is its own multi-select. Tick every measure the study assessed within it; leave the domain blank if it assessed nothing there. Every domain has an Other box (use + for several).

A tick marked + opens guidance: which named instruments belong under it, and where the near-misses go instead. More will be added as reviewers ask — tell us which ticks are causing hesitation.

Cognitive

cognitive task batteries

Other
Ticks attention/processing speed
DSSTTrail Making A simple/choice reaction time PVTCPT RVIPcancellation tasks (d2)

Rule of thumb: the whole task is respond quickly and keep responding. The difficulty comes from speed or from sustaining vigilance — not from holding something in mind and doing work on it.

Goes elsewhere
  • Executive function Stroop, flanker and any task whose difficulty is conflict or interference — even when the outcome reported is a reaction time. Same domain, the other tick.
  • Other outcomes self-reported concentration or "brain fog" scales. This domain is tasks; a questionnaire about attention is not a cognitive outcome.
Ticks creativity/divergent thinking
Alternate Uses Task (AUT)Torrance (TTCT) Remote Associates Test (RAT) Picture Concept Task

Rule of thumb: the tick is creativity — divergent is just its commonest form. Convergent creativity tasks (RAT, insight problems with an "aha" solution) belong here too, not under executive function.

Goes elsewhere
  • Psychological process personal or psychological insight (PIQ and similar) — a different sense of the word "insight" from the problem-solving one.
Ticks executive function
n-backStroop Go/No-Gostop-signal task switchingTrail Making B backward digit spanWCST Tower of Londondelay discounting

Rule of thumb — manipulating beats storing. If the task asks the participant to update, inhibit, switch or plan, it is executive function even when the material being held is memory-like. The n-back is the case that catches people: it looks like a memory task, but the load is continuous updating, so it ticks here and not memory. Backward digit span goes the same way for the same reason.

Goes elsewhere
  • Memory word-list learning, delayed recall, recognition — bringing information back rather than working on it. Same domain, the other tick.
  • Attention simple reaction time and vigilance, where nothing has to be held or overridden. Same domain, the other tick.
Ticks memory
RAVLTCVLTHVLT delayed/cued recallrecognition memory Rey figure recallpaired associates forward digit spanautobiographical memory

Rule of thumb: the participant has to bring something back after a list or a delay. Encoding, retention and retrieval — not manipulation.

Goes elsewhere
  • Executive function n-back and backward digit span. Working memory under continuous updating is an executive task, however memory-like the name. Same domain, the other tick.
Ticks social cognition
RMET (Eyes test) Multifaceted Empathy Test (MET) emotional face recognition (Ekman/FERT) emotional prosody theory-of-mind storiesCyberball

Rule of thumb — is there an answer key? Social cognition is a performance task about another mind: reading someone else's emotion or intention, scored right or wrong against an external key. If there's a correct answer about another person, it ticks here.

Goes elsewhere
  • Emotional processing the overlap case — and often not either/or. One emotional-face paradigm can yield several measures, and each is ticked on its own: label accuracy ("which emotion is this?") → social cognition, here; the participant's reactivity to the faces (amygdala response, dot-probe bias, startle) → emotional processing (Psychological process). A task scored for accuracy and recording a response ticks both.
  • Psychological process trait empathy and compassion questionnaires (IRI, self-compassion scales) — self-report about the self, not a scored reading of others.
  • Neuroimaging / Physiological the recording method is its own tick, on top of the construct(s) above: fMRI or EEG → Neuroimaging (task fMRI); skin conductance, heart rate or startle → Physiological/Autonomic. A scanner faces task can tick social cognition, emotional processing and task fMRI.

Drug experience questionnaires

Persisting (PEQ; not HPPD) Other

The field's standard measures of the acute drug experience all live under this one tick. Tick it once, however many of them a study ran — the specific instruments go in the measure text, not into separate ticks.

Ticks Acute
ASC (5D-ASC · 11D-ASC/OAV) MEQ (MEQ30 · MEQ43) CEQ intensity ratings VAS subjective-effect ratings EBI

Rule of thumb — ask what the instrument is about, not when it was filled in. If it asks about the drug effect (how strong, how strange, how mystical, how difficult), it is Acute. A questionnaire completed after the session asking what the session was like is still Acute; one asking how you are now is not. If a mood scale is administered during the session to capture the present state, it is still Acute.

Goes elsewhere
  • Persisting PEQ and other "what has changed since?" questionnaires — same domain, the other tick.
  • Safety & tolerability HPPD / persisting perceptual changes, and session adverse events.
  • Psychiatric mood and symptom scales (POMS, STAI, BDI), administered before/after the session.
  • Trial integrity blinding guesses and expectancy ratings.
  • Psychological process connectedness, insight, compassion and similar constructs measured as outcomes at follow-up.
  • Sensorimotor psychophysical and perceptual tasks — performance, not self-report.

Domains are independent: an ASC and a POMS in the same paper is two ticks, not a choice.

Psychiatric

named disorders + two catch-alls — reach for a catch-all only when the measure spans disorders

anxietyburnout depressioneating disorder mania/hypomaniaOCDPTSD psychotic symptomssubstance use Other
Ticks general mood/affect
POMSPANAS Bond-Lader VAS Visual Analogue Mood Scale (VAMS) mood VAS

Rule of thumb — current feeling, not a diagnosis. A general mood-state measure spanning positive/negative affect, not tied to one disorder. The axis is how the person feels now.

Goes elsewhere
  • depression / anxiety a disorder-specific severity scale (BDI, MADRS, HAM-D; STAI, GAD-7) ticks that named disorder — not this catch-all. Use general mood/affect only when no single disorder owns the instrument.
  • general psychopathology a broad multi-symptom index (SCL-90, BSI) is symptom burden, not mood state — the other catch-all.
  • Acute (Drug experience) a mood scale run during the session to capture the acute drug state is Acute; the same scale at baseline and follow-up, as a trial outcome, is general mood/affect, here.
Ticks general psychopathology
SCL-90-RBrief Symptom Inventory (BSI) BPRSGHQ Hopkins Symptom Checklist (HSCL) CGI-Severity

Rule of thumb — breadth of symptoms across disorders. A broad symptom-burden index that aggregates clinical symptoms over several domains, or a global illness-severity rating. The axis is how much clinical symptomatology, not one condition.

Goes elsewhere
  • a specific disorder if a study reports the depression subscale of the SCL-90 as its depression outcome, tick depression; only the total / global severity index ticks general psychopathology.
  • general mood/affect a mood-state measure (POMS, PANAS) is affect, not a symptom inventory — the other catch-all.
  • global functioning (Functioning box) WHODAS / disability measures impairment — what the person can't do — not symptom burden. Symptoms here, functioning there.

Functioning and well-being

two axes: what the person can do (functioning) and how they rate their life (well-being)

Other
Ticks global functioning
GAFWHODAS 2.0 Sheehan Disability Scale (SDS) Work & Social Adjustment Scale (WSAS)

Rule of thumb — disability, not symptoms. An overall rating of impairment across life domains: how much the condition limits what the person can do. Tick this for the composite; tick the occupational or social slice as well if the study breaks those out.

Goes elsewhere
  • Quality of life/well-being the classic mix-up: WHODAS (disability — what you can do) is global functioning; WHOQOL (how you rate your life) is quality of life. Same "WHO", opposite construct.
  • Psychiatric symptom-severity scales (a depression or anxiety score, CGI severity) — that's the illness, not the functional impairment.
Ticks mindfulness
FFMQMAAS decentering (Experiences Questionnaire) Toronto Mindfulness Scale

Rule of thumb: a dedicated trait/state mindfulness scale — present-moment awareness, non-reactivity, decentering.

Goes elsewhere
  • Psychological flexibility (Psychological process) the ACT constructs — acceptance, defusion, experiential avoidance (AAQ-II). Related family; mindfulness scales tick here, the AAQ-II ticks there.
Ticks occupational/role functioning
return to work days worked / absenteeism SDS work subscale SF-36 role subscales

Rule of thumb: the work / study / role slice specifically — productivity, return to work, role performance.

Goes elsewhere
  • Global functioning a single composite disability score (WHODAS, GAF) rather than the work slice broken out.
  • Social functioning the relationships / sociability slice. A measure that spans both (WSAS) is usually recorded as global.
Ticks social functioning & sociability
Social Adjustment Scale (SAS-SR) SF-36 social subscale loneliness (UCLA) social network / relationship quality

Rule of thumb — behaviour, not felt connection. Actual social functioning: relationships, social adjustment, sociability, loneliness as a life circumstance.

Goes elsewhere
  • Connectedness (Psychological process) the felt sense of connection to others/self/nature (Watts Connectedness Scale, IOS). The reciprocal of this tick: felt connection is a psychological process, social behaviour is functioning — a study can report both.
  • Social cognition (Cognitive) a scored task reading others' emotions or intentions — an ability, not everyday social functioning.
Ticks quality of life/well-being
WHOQOL-BREFSF-36 EQ-5DWEMWBS Satisfaction With Life (SWLS) Flourishing ScaleRyff PWB

Rule of thumb — a subjective evaluation of one's life as a whole, or general well-being/flourishing. How the person rates their life, not what they can do.

Goes elsewhere
  • Global functioning WHODAS / disability — what the person can do. The WHOQOL-vs-WHODAS split again, from the other side.
  • Psychiatric mood and affect symptom scales (depression remission, positive affect on the PANAS) — a symptom outcome, not a life-quality rating.

Psychological process

self-report constructs, usually measured as outcomes at follow-up

Other
Ticks connectedness
Watts Connectedness Scale (WCS) Inclusion of Other in Self (IOS) Social Connectedness Scale nature relatedness

Rule of thumb: a felt sense of connection — to other people, to oneself, to nature or the world. The self-report construct, not the behaviour and not the transient unitive state during dosing.

Goes elsewhere
  • Acute (Drug experience) the unitive / oceanic-boundlessness experience during the session — that's the mystical-experience item on the ASC or MEQ, not an enduring connectedness outcome.
  • Spirituality connection to something greater / the sacred, when framed spiritually. Neighbouring tick; both can apply.
  • Social functioning & sociability (Functioning box) actual relationships and social behaviour — what you do, not what you feel connected to.
Ticks compassion
Self-Compassion Scale (SCS) Santa Clara Brief Compassion compassion-for-others scales

Rule of thumb: a self-report of compassionate attitude toward self or others. There is no answer key — the participant rates themselves.

Goes elsewhere
  • Social cognition (Cognitive) empathy measured as a performance task scored for accuracy — the MET, the Eyes test. Reading others correctly is an ability; feeling compassion is a self-rated attitude.
Ticks emotional processing
Emotion Regulation Questionnaire (ERQ) DERS alexithymia (TAS-20) Emotional Processing Scale (EPS)

Rule of thumb — own affect, no answer key. How the participant responds to, regulates or works through their own emotions. Self-report or an affective response, never scored right/wrong against another person's state.

Goes elsewhere
  • Social cognition (Cognitive) the reciprocal — and these aren't mutually exclusive. An emotional-face task scored for label accuracy ticks social cognition, while the reactivity it evokes (amygdala response, dot-probe, startle) ticks emotional processing, here — the same task can do both.
  • Psychological flexibility experiential avoidance / the AAQ-II live under that neighbouring tick; keep emotional processing for emotion regulation and alexithymia specifically.
  • Acute (Drug experience) emotional breakthrough during the session (EBI) is an acute drug-experience measure.
  • Psychiatric mood and affect symptom scales (POMS, PANAS as a state measure) — mood level, not the processing of emotion.
Ticks insight
Psychological Insight Questionnaire (PIQ) Psychological Insight Scale (PIS)

Rule of thumb — which "insight"? This tick is psychological / personal insight: new understanding of one's own patterns, relationships or life, typically credited to the experience. The word has two other senses that go elsewhere.

Goes elsewhere
  • Creativity/divergent thinking (Cognitive) problem-solving insight — the "aha" solution to a puzzle (RAT, insight problems). A performance task, not self-understanding.
  • Psychiatric clinical insight into illness (does the patient recognise they are unwell) — a symptom-level construct, rare here.
Ticks personality/neuroticism
Big Five / BFINEO-PI-R opennessneuroticism absorption (Tellegen)

Rule of thumb: a trait personality inventory measured as an outcome — openness and neuroticism are the ones psychedelic trials report most. Enduring dispositions, not current symptoms.

Goes elsewhere
  • Psychiatric current mood, anxiety or general psychopathology symptoms — a state, not a trait inventory.
Ticks psychological flexibility
AAQ-IICompACT experiential avoidance cognitive fusion (CFQ)

Rule of thumb: the ACT construct — acceptance, defusion, values-based action, and their inverse, experiential avoidance. The AAQ-II is its home instrument.

Goes elsewhere
  • Emotional processing emotion-regulation and alexithymia measures (ERQ, TAS-20). Related literature, neighbouring tick — flexibility is the wider acceptance/avoidance construct.
Ticks rumination
Ruminative Responses Scale (RRS) brooding subscale Perseverative Thinking Questionnaire (PTQ)

Rule of thumb: a dedicated repetitive-negative-thinking measure. Tick it when rumination is measured in its own right.

Goes elsewhere
  • Psychiatric a depression scale that happens to contain a rumination item (e.g. the BDI) is a depression outcome — tick depression there, not rumination here. If the paper reports specifically on rumination as a sub-scale, tick rumination here.
Ticks spirituality
Daily Spiritual Experience Scale FACIT-Sp (spiritual well-being) WHOQOL-SRPB religiosity / faith measures

Rule of thumb: enduring spirituality, religiosity or the sacred, measured as a trait/outcome. Not the peak mystical state itself.

Goes elsewhere
  • Acute (Drug experience) the mystical experience during the session — the MEQ and the ASC's oceanic-boundlessness — is an acute drug-effect measure, not an enduring spirituality outcome. This is the commonest mix-up in the box.
  • Connectedness connection to self/others/nature framed secularly. Neighbouring tick; both can apply when a scale spans them.
