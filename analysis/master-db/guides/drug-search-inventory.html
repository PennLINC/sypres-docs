Part 2 · for decision

Embase-only terms from the “psychedelic agent” branch

Embase indexes records with EMTREE, its own controlled drug/disease vocabulary. The Embase drug clause anchors on the EMTREE term 'psychedelic agent' and then names a set of its narrower terms. That branch is why Embase searches a handful of compounds the other four databases never mention — and it hinges on the difference between two Embase operators.

/exp — explode

The term plus every narrower term beneath it in the EMTREE hierarchy. Exploding 'psychedelic agent' pulls in its whole subtree — including cannabinoid, whose own large subtree (cannabis, THC, CBD…) flooded the results.

/de — descriptor, not exploded

Records tagged with that exact term only; no narrower terms come along. So 'psychedelic agent'/de keeps articles indexed to the umbrella term itself without dragging in any children.

The fix already in the strategy is the standard “prune one branch” move: search the parent as 'psychedelic agent'/de (umbrella hits, no children), then manually OR back in each wanted child as 'child'/exp, deliberately leaving out cannabinoid. Most of the re-added children map to compounds already covered everywhere by free text (lysergide, mebufotenin, mescaline, midomafetamine, psilocin, psilocybine, bretisilocin, luvesilocin, deupsilocin). Seven do not — these are searched in Embase and nowhere else:

They were pulled in as a side effect of keeping the 'psychedelic agent' children (minus cannabinoid) — not from a deliberate decision that each belongs in scope.

Correction needed: deudimethyltryptamine (deuterated DMT) was left out of Embase by error fix

The same 'psychedelic agent' EMTREE branch also lists deudimethyltryptamine (deuterated DMT), but it was not included in the Embase OR-list — an omission, not a scope decision. Deuterated DMT is in scope: it is exactly the compound behind the HLP-004 code name (Helus Pharma, IM deuterated DMT) already searched in every database. As it stands, Embase catches it only by the HLP-004 code name and misses any record indexed generically to the EMTREE term. Recommended fix: add 'deudimethyltryptamine'/exp to the Embase drug clause.

What the team decides

Open decisions

The shared inventory compounds are captured correctly in every database (the divergence is elsewhere); these choices concern the Embase-only branch, one omitted term, and one spurious token. The guiding principle already agreed: if we search for a compound, we intend to include it — so the question is which terms we meant to search, then making all five databases agree.

  1. Add 'deudimethyltryptamine'/exp to Embase — recommended

    A known omission of an in-scope compound (deuterated DMT / HLP-004). Low-risk, closes the gap. No effect on the other four databases.

  2. Are bufotenin, 5-MeO-DiPT, and (optionally) salvinorin A in scope?

    If yes, mirror them into PubMed / Scopus / Web of Science / PsycINFO as free-text terms (e.g. bufotenin*, 5-MeO-DiPT / foxy, salvinorin* / salvia divinorum) so coverage is symmetric. If no, remove them from Embase.

  3. Drop the out-of-scope terms from Embase?

    Lysergic acid, elymoclavine, tenocyclidine, and the mescaline aziridine analog are not psychedelics administered in trials. Removing them from Embase tightens consistency; leaving them adds only rare, easily screened-out noise. Either is defensible — the point is to choose deliberately.

  4. Remove MDMT from all five databases? — recommended

    There is no established psychedelic — and no trial-tested drug — named MDMT. The term looks like a pattern-completion of the methylenedioxy series (MDMA, MDMC, MDMT) rather than a real target, and its “3,4-methylenedioxy…tryptamine” reading uses amphetamine-ring numbering that doesn’t map onto a tryptamine. As a bare token it is also an ambiguous acronym (e.g. “minimum design metal temperature”), so it adds false-positive risk while contributing no sensitivity. It is searched in all five databases, so removal is a one-line edit in each. (If methylenedioxy-tryptamine coverage is genuinely wanted, the real names are 4,5-MDO-DMT and similar — but none has an RCT.)
