How to use this list

  • In scope means administered. A trial is in scope if it administers any compound on this page, in any arm and at any dose — including microdose programmes and the non-hallucinogenic analogs marked below.
  • Look for every name. One compound can appear as an INN, a chemical name, a street name or a development code, and renamed programmes carry two codes. Code names are shown as their developers write them; the search covers both hyphenated and run-together spellings (SPL-026 and SPL026).
  • Excluded compounds can still appear. A compound under Not included can be the comparator or co-administered drug in an included trial.

Part 2

Not included

A trial that administers only these is out of scope. They can still appear in an included trial as a comparator or co-administered drug — the database holds two DMT trials with ketamine as the active comparator (Daumann 2008, 2010).

Group Compounds Why not
Dissociatives ketamine, esketamine, PCP (phencyclidine), tenocyclidine (TCP), NR2B negative allosteric modulators NMDA-receptor antagonists — a different mechanism. The search contains no dissociative terms.
Stimulants & cathinones 4-fluoroamphetamine (4-FA), α-PVP (a-PVP), mephedrone (4-MMC), 3-MMC (metaphedrone) Monoamine-releasing stimulants. Methylone is the exception: it is MDMA's direct β-keto analog.
Piperazines BZP, TFMPP, mCPP (chlorophenylpiperazine) Stimulant or serotonergic “party pills” and challenge agents — not 5-HT2A psychedelics.
Aminoindanes MEAI (CMND-100) An alcohol-substitute empathogen. It appears in psychedelic pipeline trackers, which cover a wider commercial sector than this review.
Depressants GHB (sodium oxybate) A GABA-B agonist.
Cannabinoids THC, CBD, cannabis Excluded by design: Embase files cannabinoids under its psychedelic agent heading, and that branch is pruned from the search.
Oneirogens Calea zacatechichi (calea) A “dream herb”; not a 5-HT2A psychedelic.
Precursors & lab chemicals lysergic acid, elymoclavine, N-(3,4,5-trimethoxyphenylethyl)aziridine Related chemistry with no use as an administered psychedelic. Removed from the Embase search in September 2026.
Not drugs MDMT, m-DASC MDMT is not an established compound — the term was a pattern-completion of MDMA and MDMC. m-DASC is a questionnaire for low-dose psychedelic effects.

Part 3

Keeping the list current

  • Quarterly pipeline review. Psychedelic Alpha publishes its drug development tracker charts each quarter. Each release is reviewed for compounds newly at phase 1 or later, and every candidate code name gets two checks before it is added: its development phase, and whether its compound is a psychedelic by this review's definition. CMND-100 (MEAI) passed the first and failed the second.
  • Renames. Programmes are renamed often — MM120 became DT120, CYB003 became HLP003, TD-0148A became BETR-001 — so both names stay searched.
  • Spellings. Code names are searched both hyphenated and run together, because databases split a hyphen differently: in Scopus and Web of Science, VLS-01 finds records VLS01 misses, while SPL026 finds records SPL-026 misses.
  • Missing a compound? If a paper administers a compound or code name not on this page, flag it rather than excluding the paper — it may be a rename, a new pipeline entrant, or a relative of a listed compound.

Open items

  • Search terms in progress. The review's librarian is building the search terms for the 10 compounds added or extended in September 2026 — 2C-B, DOI, DOM, DOET, DPT, MDA, MDE, bufotenin, 5-MeO-DiPT and salvinorin A — and the free-text forms deupsilocin* and deudimethyltryptamine*. All are listed here as included already; inclusion does not wait on search syntax.
  • Noribogaine and GM-3009 are not yet searched as free text. iboga* can't reach “noribogaine”, and GM-3009 is Gilgamesh's own spelling of GMX-3009. Neither changes today's results.
  • RE01 and RE02 (Reconnect Labs) are searched as RE01-SL and RE02-SL. In the pipeline tracker “SL” is the route (sublingual), not part of the code. Neither spelling works as a search term: the -SL forms match nothing, and bare RE01 and RE02 match only unrelated records. Trials of these products are reached through DMT and 5-MeO-DMT.

Change log

What changed, and the decisions behind it

30 Sep 2026

Rewritten as the reviewer reference for what's included

Changes to this guide

  • Purpose. The 9 September edition was a decision document for the team. This edition is the reference reviewers use to decide whether a trial's drug is in scope. Its open decisions are resolved and their outcomes are recorded below.
  • Structure. Reorganised into 12 compound families with one row per compound — its identity, every searched name and heading, and its development code names with developers. Added a find box, the Not included list, maintenance notes and open items.
  • Counting. The list now holds 35 compounds and 56 development code names. The first edition's 34 counted combination products (such as RE01, NBX-100 and SON-001) as separate compounds and included the Embase-only terms; this edition counts distinct active compounds, with combination products under their psychedelic component. LSD-25 and BOL-148 are listed as names rather than code names.
  • Corrections. GH001's developer was given as Beckley Psytech; it is GH Research, which also develops GH002 (Beckley's 5-MeO-DMT programmes are BPL-002 and BPL-003). VLS-1 is no longer listed as an alias of VLS-01. RE01 and RE02 now appear under their real code names.

Decisions made in September 2026

  • Inclusion rule. If the search looks for a compound, trials administering it are included — at any dose, including microdose programmes and non-hallucinogenic analogs (BOL-148, zalsupindole, tabernanthalog, EB-003, EQL-101).
  • Added from screening: 2C-B, DOI (including R-DOI), DOM, DOET, DPT, MDA and MDE/MDEA — 5-HT2A phenethylamines and tryptamines, and MDMA-family entactogens. The phenethylamines close a gap: mescaline had been the only one searched. The database already held 6 MDA studies and 1 2C-B study, found through the class terms.
  • Extended to all five databases: bufotenin, 5-MeO-DiPT and salvinorin A, previously searched in Embase only. Salvinorin A, a κ-opioid agonist, is a deliberate widening of the mechanism boundary; two salvinorin A studies are already included.
  • Added from the pipeline tracker: 12 code names at phase 1 or later from Psychedelic Alpha's Q3 2026 charts — GH002, BMND06, BMND08, BMND09, RE02, MSP-2020, NPX-5, PEX010, ALA-002, AM-1002, NBX-010 and LPH-5 — plus SPL026, which has left the tracker but has published trials.
  • Predecessor code names: CYB003 and CYB004, the names HLP003 and HLP004 carried before Cybin became Helus Pharma.
  • Removed: MDMT, which is not a real compound; VLS-1, which matched viral-load abbreviations (11 PubMed records, none relevant); lysergic acid, elymoclavine, tenocyclidine and N-(3,4,5-trimethoxyphenylethyl)aziridine from Embase; and CMND-100 (MEAI), added from the tracker, then reverted as outside the mechanism boundary.
  • Fixed: deudimethyltryptamine added to the Embase search, from which it had been left out by error.
  • Ruled out from screening: TFMPP, BZP, mCPP, PCP, NR2B negative allosteric modulators, α-PVP, 4-fluoroamphetamine, mephedrone, 3-MMC, GHB and Calea zacatechichi. m-DASC, which had been listed among the drugs, is a questionnaire.
  • Search syntax — no change to what is included: code names are now searched hyphenated and run together, without proximity operators, in all five databases. This removed 124 irrelevant records across the five final searches; all 63 dropped records checked in PubMed and Scopus were unrelated.
  • Standing process: the Psychedelic Alpha tracker is reviewed each quarter, with the two-part check on development phase and mechanism.
